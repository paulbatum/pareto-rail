# GLM 5.3 Flash: formerly Ox Alpha

OpenRouter revealed `stealth/ox-alpha` as `z-ai/glm-5.3-flash`. The benchmark keeps the configuration id `pi-openrouter-ox-alpha-high` and all six level ids so existing votes remain attached to the same configuration.

The six recorded runs now use the normal GLM 5.3 Flash rate card:

- $0.15 per 1M input tokens
- $0.50 per 1M output tokens
- $0.03 per 1M cached input tokens

The runs were repriced from their retained token counts rather than re-measured. Their published generation costs are now available, so the configuration appears on the quality-versus-cost chart. The public model label is **GLM 5.3 Flash**; the old Ox Alpha name remains only where the retained run records identify the route originally used.
