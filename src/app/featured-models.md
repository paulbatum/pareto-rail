# Featured models

The models named on the home page, in the order they appear there.

This list is site copy, not a projection of the catalog: a model belongs here once
it is running the benchmark, which is earlier than its first level publishes. Add
`(new)` after a name to mark it as a recent arrival, and drop the marker once it
stops being news. Write a name as a markdown link to give it a destination — the
home page renders those as external links and plain names as plain text. Follow a
name with an em dash and a short phrase to add a note; the home page gives an
entry with a note its own full-width row, so keep notes rare.

The name is what the catalog is reconciled against, so it stays the model's name
alone — a note or a link never changes it.
